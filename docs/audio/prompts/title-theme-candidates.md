## Candidate A — institutional restraint

> Create an original, instrumental 30-second title-screen theme for a premium political narrative game about the quiet pressure of governing a young democracy. Use a slow 70 BPM pulse in 4/4 and D minor with restrained warm color. Build both candidates around the same four-note motif, D–A–F–E, and the same slow harmony: Dm(add9), Bbmaj7, F/A, C(sus2), resolving softly to Dm(add9). For this version, use sparse felt piano with long silences and a low, intimate cello line; add only a faint natural room tone. Let the motif appear twice, with the second statement slightly more open, then give the phrase a composed, quiet ending. Keep dynamics restrained and leave clear space around each note. No vocals, percussion, fanfare, triumphant anthem, dramatic trailer build, familiar melody, or recognizable imitation.

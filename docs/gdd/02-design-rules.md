## Key decisions (summary)

| Decision | Locked value |
| --- | --- |
| <b>Compass visibility</b> | <b>Never shown to player</b> — consequences only |
| <b>Resources</b> | Always visible (PT, FC, IPI, EPI) |
| <b>Approval</b> | Shown as a number (e.g. 52.8%) |
| <b>Choice feedback</b> | None — no "loyalty gained" popups |
| <b>Progress indicator</b> | None |
| <b>UI mode</b> | REST STATE (world map) ↔ VN MODE (dialogue) |
| <b>Free actions</b> | Toggleable sidebar; targeted free actions use two-stage click |
| <b>Audio</b> | Licensed ambient music, no voice acting |

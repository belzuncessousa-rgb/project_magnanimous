# Political compass

## Compass System

Seven hidden axes, each ranging from −10 to +10. <b>Never shown to the player.</b> Consequences play out through dialogue, events, and character behavior.

| Axis | Negative pole | Positive pole |
| --- | --- | --- |
| <b>ECON</b> | Free-market | State-interventionist |
| <b>WELF</b> | Austere | Redistributive |
| <b>IDEN</b> | Cosmopolitan / progressive | Nationalist / identitarian |
| <b>FORCE</b> | Diplomatic | Militarist |
| <b>STRUCT</b> | Democratic | Authoritarian |
| <b>RELIG</b> | Secular | Religious |

Every player choice moves one or more axes. Axis values accumulate across all six periods. Characters have their own compass positions — <b>loyalty drifts when the president's compass diverges from a character's convictions</b> beyond a threshold.

Besides a political compass, each entity must have a vector of relevance. That is, how relevant each axis is to said entity. This vector will later be combined with the difference in political compass to calculate other indeces. The vector is in percentages of importance from 0-1. As exemple: \[0.9, 0.5, 0.4, 0.1, 0.4, 0.8\]

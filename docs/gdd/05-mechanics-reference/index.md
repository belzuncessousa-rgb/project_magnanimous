# 5. Mechanics Reference

The game is divided into 2 terms with 6 chapters each. Each chapter has 3 turns. A turn is the repetitive structure in which the player interacts with the game. Turn structure is described in [Turn Structure](turn-and-game-structure/index.md).

To keep track of interactions and states, the game has several entities: Characters; States; Foreign Nations; Own nation.<br />The control of everything in the game is divided into [indices](indices/index.md) (entity values), [resources ](resources.md)(spendable by the player) and [flags ](flags.md)(introduced through the game and are always global). Special attention must be given to the [political compass](political-compass.md), which is a characteristic of each entity and may impact resource generation and indices’ rest values. Other particular set of characteristics is the [taxation system](taxation-system.md) that will also be explained separately.

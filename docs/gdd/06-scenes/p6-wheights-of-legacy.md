# P6 — Wheights of Legacy

<b>Dramatic question:</b> What remains?

<b>Period arc:</b> The final period. The ending is determined by the sum of all decisions — there is no "pick your ending" menu. The game reads the compass state, resource levels, character loyalties, and flag history and delivers the appropriate ending.

## Ending categories

| Category | Condition |
| --- | --- |
| Legacy endings | Complete two terms, positive approval and stability |
| Voluntary Exit | Player survives but chooses not to seek second term |
| Legitimacy Death | Approval collapses; government falls without coup |
| Coup | Military moves when power axis + armed forces loyalty reach threshold |
| Corruption implosion | Pelan Avros / cartel corruption becomes irresolvable |
| Theocratic drift | Elom Durres pastor-mandate path taken to completion |
| Constitutional crisis | Institutional breakdown from accumulated authoritarian moves |

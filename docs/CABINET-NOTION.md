# Cabinet & ministries — what the new GDD already defines (Notion: 5. Mechanics Reference → Ministries & Cabinet)

- Term-1 cabinet is FIXED (pre-election coalition). Player builds own cabinet only in term 2.
- Chapter 2: player sets each ministry's budget tier: Cut(0) / Low(1 initiative, player picks) / Regular(2) / High(3, only
  Development, Defense, Law & Order). Each tier costs FC per turn. Mid-term re-budget alongside the debt meeting.
- Standing themes fire regardless of budget. Minister mood reacts only to the player's choices; displeasing lowers IPI and
  affects which factions join the 2nd-election coalition.
- Ministry visits: e.g. at an opening ceremony the president steers the focus of an initiative (speech line → effect).

# Audio assets

Game-ready audio will live here, grouped by use:

- `music/` — title, map, dialogue, and crisis loops
- `sfx/` — short interface and interaction sounds
- `stingers/` — one-shot narrative and state-change sounds
- `ambience/` — room and event beds

The planned inventory and production notes are in [`docs/audio/SOUND-PLAN.md`](../../docs/audio/SOUND-PLAN.md). No audio files have been approved or integrated yet. Record source and license details before adding a file for release.

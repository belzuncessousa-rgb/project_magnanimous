# DEMO CONTENT — placeholder only

Everything in `content/_demo/` is throw-away fixture content so the engine runs before the real story lands.
The loader uses a demo category (scenes, world, characters, chapters, news, pop-ups, free actions, crises) only
when the matching real file under `content/` is missing. Story-bound demo files (chapters, news, pop-ups, crises)
are ignored as soon as any real scene exists. Do not extend this to write the real story.
